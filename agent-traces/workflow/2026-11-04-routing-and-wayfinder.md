# Task routing, Wayfinder and delegated context

- Goal: bundle grill-with-docs, Wayfinder and their transitive resources; use proportionate request routing and delegate substantive work while reserving all pure context collection for fresh GPT-6 Luna low agents.
- Changes: strict independent `grill-with-docs=true` and `wayfinder=true` defaults reuse existing resolver/backfill validation. Canonical policy, orchestrator, hook guidance and discovery metadata select tiny direct work before setup, clear stack goals, unclear grill-with-docs before goal, or large Wayfinder work with parallel dependency-ready ticket phases. Legacy `grill-me` remains supported/default true for explicit invocation without an extra automatic interview.
- Delegation: context agents return referenced facts/notes only, no implementation/source/config changes or design decisions; separate substantive interview/planning/documentation roles use them. Root retains route selection, user-question/approval relay, native goals and evidence review, and schedules all ticket phases within host slots and isolated writes. One-active-goal hosts use explicitly textual/unregistered child ticket goals under the root umbrella. Preparatory tickets need a clear own question, while implementation tickets require their design decisions settled.
