- Goal: make repository checks repeatable on Windows/Linux and distinguish actual candidate discovery, model execution and independently asserted fixture behavior.

- Why: deterministic hooks and text contracts do not establish host/model behavior; normal CI must not require protected model credentials.
- Checks: initial RED proved missing workflow/runner; initial focused GREEN passed 23 harness/CI tests. Actual local CLI 0.171.0-alpha.13 executed model `gpt-6.1-sol` and emitted thread/turn/item events with numeric usage. Those two owned probe trees were removed (including read-only Git objects); protected originals were not changed or printed. The runner now installs only an allowlisted staged source, rejects links, and excludes credential/evidence/cache names before hashing or copying. Real installer discovery is fingerprint-bound to the candidate; it is distinct from authenticated project-skill behavior and automatic hook execution.
