- Scope: stack orchestration, task preparation, skill dependencies and project configuration.
- Requested behavior: this is a new requirement, not a reported runtime failure. Tiny low-risk changes use a delegated direct path without stack overhead. Clear normal work uses stack plus goal; unclear normal work uses grill-with-docs before the goal; large work uses wayfinder followed by every unblocked ticket in parallel through stack plus goal. The active session coordinates and delegates substantive work with sufficient context.
