# ADR 0004: Proportionate routing and delegated context

- Date: 2026-11-04
- Status: accepted by the user's requested routes and confirmed configuration semantics.

## Decision

Classify ordinary work before setup. Tiny bounded low-risk edits delegate directly with focused checks; clear normal features/bugs use stack plus goal; unclear normal work uses grill-with-docs before goal; large work uses Wayfinder followed by every dependency-ready ticket in parallel through stack goals. The active session coordinates and delegates substantive work. All pure information collection, including pre-interview/pre-goal facts, exclusively uses fresh GPT-6 Luna low agents with referenced factual notes and no implementation/design decisions.

Use independent strict Boolean `grill-with-docs=true` and `wayfinder=true` defaults. Keep `grill-me` supported/default true for compatibility and explicit use, replacing its automatic pre-goal interview with request routing. Preserve separate plan-mode approval, enabled applicable evaluation gates on stack work, onboarding, trust, preservation and external-write permissions.

## Rationale and consequences

Unconditional setup/interview/three-role overhead costs more than a tiny clear correction. A direct route escalates before wider edits when risk, uncertainty or scope grows. Clear work avoids an invented interview; unclear work retains real human decisions and glossary/ADR persistence. Large work retains map/claim/dependency evidence, bounded phase scheduling, write isolation and integration verification instead of requiring three simultaneous agents per ticket.

One-active-native-goal hosts retain a root umbrella with explicitly textual/unregistered strong child goals; only root manages native goals. Missing requested research controls blocks required collection without silent fallback. This is an agent instruction workflow; contract/helper tests cannot prove future model decisions or host execution compliance.
