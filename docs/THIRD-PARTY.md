All 39 UIUX data files and 28 script/test files from the CLI assets were compared with the installed copy: byte-identical, excluding interpreter caches. The runtime checker performs a real search. This proves the delivered resources, not future upstream completeness. Font/icon provenance files are retained.

Modifications: request routing replaces automatic legacy `grill-me` while retaining its strict Boolean compatibility key and explicit invocation. Grilling resumes across replies, limits decisions to scope, uses fresh Luna-low factual researchers and continues without upstream closing confirmation; plan-mode and permissions remain independent. Tracker setup now uses the strict authoritative provider/location config and stack-owned setup/check helper to render those existing templates; local is the omitted-setting default, selected hosted failure never silently falls back, and exact pending first-init settings precede config-last creation. New adapted entrypoints link the shared policy, use portable sibling skill invocation, delegate substantive roles and require actual human answers. Wayfinder overrides upstream's plan-only stop and one-ticket-per-session limit: root schedules all ready ticket phases with claims, dependencies, isolated writes and host-compatible goals. Research/handoff collect facts only; prototypes retain local artifacts and focused safeguards; tracker setup cannot automatically initialize Git, alter remotes or publish labels/issues/branches. Supporting formats and guides come from the pinned source; tracker scheduling/permission guidance and the UI prototype safeguard description are narrowly adapted and marked in those files. Optional onward to-spec/to-tickets/implement/ask-matt workflows and the separately optional triage skill are not required invocations or imported dependencies; the conditional triage-label template is included.

UIUX skill examples use the directory of the loaded plugin skill file instead of a global installation. In the Ponytail gain skill, only source references were adjusted to the bundled benchmark/README copy. The combined `hooks/hooks.json` adds stack handlers and accepts both host plugin-root variables. Original Ponytail JavaScript files and rules are unchanged. The affected skill texts identify the modifications.

[bundle-manifest.json](../assets/bundle-manifest.json) contains SHA256 hashes of delivered skills, hooks, and licenses. License texts come from the installed Ponytail package or official upstream repositories. Personal runtime paths and credentials do not belong in provenance records.
